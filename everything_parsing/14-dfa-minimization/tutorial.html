Everything Parsing · Module 14 · Part II — Lexical Analysis

DFAMinimization

Two states are the same if the machine's future is the same from either. Merge every such pair and you get the minimal DFA — and by the Myhill–Nerode theorem it is unique. That uniqueness turns "do these two regexes mean the same language?" into a decidable question.

The pipeline is now complete and optimal

regex → NFA → DFA → minimal DFA. The 5-state subset DFA for (a|b)*abb minimizes to 4 — isomorphic to the DFA a human wrote by hand in Module 10, which was already minimal.

01

The Big Analogy — the building inspector merging rooms

The subset construction handed you a building where some rooms are functionally identical: standing in either one, every sequence of doors you could walk leads to the same outcome — you reach an exit, or you don't, under exactly the same instructions.

A building inspector walks through with one rule: if two rooms are indistinguishable, knock down the wall between them and call it one room. They start with the one obvious split — "exit rooms" vs. "everything else" — and keep separating: two rooms in the same pile are actually different if door a leads from them into different piles. Re-sort. Repeat until a pass changes nothing. What's left: the fewest rooms with genuinely distinct futures.

And there is exactly one such floor plan. Any architect who minimises this building — by any method — ends up with the same rooms and the same doors. That's Myhill–Nerode.

So to ask "are these two buildings the same?" you minimise both and check if they're the same plan. For regex buildings this always works. For grammar buildings (Part IV) it provably doesn't — there is no unique minimal form.

02

What Happens, Step by Step

0. Trim. BFS from the start; drop any state you can't reach.

Method A — partition refinement (Moore):

  1. Partition = {accepting} | {non-accepting}.
  2. Each round: give every state a signature = (its block, then the block of δ(state, a) for each symbol a). States with different signatures go to different new blocks.
  3. Stop when a round creates no new block.

Method B — table filling:

  1. Mark every pair (p, q) where exactly one is accepting.
  2. Repeatedly: mark (p, q) if some symbol sends it to an already-marked pair.
  3. Stop at a fixed point. Unmarked pairs are equivalent; union them into classes.

Build the quotient DFA: one state per class (start's class first, named M0), transitions read off any representative, a class is accepting iff its representative is.

Regex equivalence — minimal DFAs, then isomorphism

static boolean equivalent(Regex a, Regex b) {
  return isomorphic(
    minimal(Subset.determinize(Thompson.build(a))),
    minimal(Subset.determinize(Thompson.build(b))));
}

static boolean isomorphic(Dfa a, Dfa b) {
  if (a.states.size() != b.states.size()) return false;
  // BFS-pair the two DFAs from their start states; any mismatch → not isomorphic
  map.put(a.start, b.start);
  while (!q.isEmpty()) {
    ... if (a.accept.contains(sa) != b.accept.contains(sb)) return false;
    for (String sym : a.alphabet) {
      String ta = a.step(sa, sym), tb = b.step(sb, sym);
      if (map.get(ta) == null) { map.put(ta, tb); q.add(...); }
      else if (!map.get(ta).equals(tb)) return false;
    }
  }
  return true;
}
Crazy detail — this is a whole decision procedure

L(a) = L(b) for regular languages is decidable, and these ~15 lines are the procedure: regex → NFA → DFA → minimal DFA → compare. For context-free languages the same question is undecidable — there is no unique minimal pushdown automaton, no Myhill–Nerode for CFLs, and the halting problem reduces to it. That gap is why Part IV can't just "equivalence-check" a grammar and instead forces it into an LL or LR shape.

05

Limits — what this module cannot do yet

Can't do yet

  • Avoid the subset construction's 2ⁿ blow-up before minimizing (Brzozowski's method dodges it differently but can still blow up mid-way).
  • Minimize an NFA — NFA minimization is PSPACE-complete, not polynomial.
  • Minimize faster than O(n²·|Σ|) — Hopcroft's O(n log n) is out of scope.
  • Tokenise — the DFA still just says yes/no (Modules 15–16).
  • Keep track of which token an accepting state means (Module 16 labels them, and must not merge differently-labelled states).

Can do

  • Compute the equivalence classes two ways and check they agree.
  • Build the unique minimal DFA for any regular language.
  • Confirm it's isomorphic to a hand-written DFA for the same language.
  • Decide, exactly, whether two regexes denote the same language.
  • Report the minimal state count = the number of Myhill–Nerode classes.

07

Brain Exercise

The subset DFA had 5 states, minimized to 4 — but in general the subset construction can blow up to 2ⁿ and then you minimize.

(1) Brzozowski's algorithm minimizes by "reverse, determinize, reverse, determinize" — no partition step at all. Why does that produce the minimal DFA? (2) Can you build the minimal DFA directly from the regex, never paying the exponential blow-up?

Answers

(1) Reversing a DFA (swap start/accept, flip every edge) gives an NFA for the reversed language. The key lemma: if you determinize an NFA whose every state is co-reachable (can reach an accepting state), the resulting DFA has no two equivalent states. Reversing then determinizing gives co-reachability for free (every subset came from a real reverse-run); doing it twice also gives forward-reachability. So after "reverse, det, reverse, det" the DFA is both minimal-reachable and equivalence-free — i.e. minimal. Elegant, though the middle determinization can still be exponential.

(2) Not in general — the minimal DFA itself can be 2ⁿ for an n-symbol regex (the "k-th from the end" family, Module 13). The blow-up is in the answer, not just the method. What you can do is build only the DFA states a given input visits — lazy determinization — which is linear per string regardless of the full DFA's size.

08

There Are No Dumb Questions

Why is the minimal DFA unique? Couldn't there be two different 4-state DFAs?

Myhill–Nerode: the states of any minimal DFA correspond one-to-one with the language's right-language equivalence classes — a property of the language, not of any machine. So every minimal DFA for a language has the same number of states and the same transition structure: they're all isomorphic.

Table filling is O(n²) pairs × O(n) rounds × |Σ|. Hopcroft is O(n log n). Is it worth learning Hopcroft?

For a lexer's DFA — hundreds of states — either finishes instantly. Hopcroft matters for genuinely huge automata (natural-language morphology, bioinformatics). Moore's method / table filling is the one to understand; Hopcroft is an optimisation of the same idea with a clever "process the smaller half" trick.

Did the dead state get merged into the start for (a|b)*abb?

There is no dead state here — from every state of that DFA you can still reach the accepting state, because (a|b)*abb lets you "start over" on a mismatched character. D0 and D2 merged because both mean the same thing: "zero characters of the suffix abb matched so far."

What's the minimal DFA for a language that rejects everything?

One state — non-accepting, self-looping on every symbol. Same shape (one state, self-looping) minimizes Σ*, except that state is accepting. Any regular language's minimal DFA has at least one state.

If I minimize, do I lose which regex position an accepting state came from?

Yes — merging discards provenance. That's fine for a yes/no matcher. For a tokeniser (Module 16) each accepting state is labelled with which token it recognises, and minimization must be told never to merge states with different labels — otherwise "keyword vs. identifier" collapses.
