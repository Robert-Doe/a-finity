Prerequisites · P4

Java & JS Setup

No build tool, no package manager, no framework. Two compilers you almost certainly already have, one 40-line test helper we wrote, and a directory layout that is identical for all 48 modules.

01

What you need

ToolMinimumCheckVerified for this course

That is the complete list. No Maven, Gradle, npm, TypeScript, JUnit, Jest. If a module ever needs something else, that will be a headline in its tutorial, not a silent dependency.

02

Every module has this shape

NN-module-name/
├─ java/            every .java file, flat
│  ├─ Assert.java       the test helper (identical copy in every module)
│  ├─ <Thing>.java      the module's library code
│  ├─ Main.java         the runnable demo
│  └─ <Thing>Test.java  the tests
├─ js/              every .mjs file, flat
│  ├─ assert.mjs
│  ├─ <thing>.mjs
│  ├─ main.mjs
│  └─ <thing>.test.mjs
├─ fixtures/        input files — BOTH languages read the same ones
├─ expected/        golden output, committed; the tutorial pastes it verbatim
├─ run.md           exact commands + expected output
├─ DECISIONS.md     line-by-line "why" for the source
└─ tutorial.html    the lesson

The Assert.java / assert.mjs in each module are byte-identical copies of the canonical pair in prerequisites/assert/. Copying beats a shared import path here: every module stays runnable on its own with one plain command.

03

The four commands

Run these from inside a module directory. PowerShell and bash are the same here.

compile + run the demo — Java

javac -d java/out java/*.java
java -cp java/out Main fixtures/inputs.txt

run the demo — JavaScript

node js/main.mjs fixtures/inputs.txt

run the tests — Java, then JavaScript

java -cp java/out <Thing>Test
node js/<thing>.test.mjs

A passing test run ends with OK N passed and exit code 0. A failure prints each bad assertion and exits 1.

04

The test helper, in full

This is the entire "framework." You are meant to read it once and never think about it again.

If javac java/*.java says "cannot find symbol Assert"

You compiled one file instead of all of them. Always compile the whole directory: javac -d java/out java/*.java. The glob is the point.
