Prerequisites

Nine small ideas every module assumes. Each module's section 00 links straight to the ones it leans on — it never re-teaches them. If a module link lands you here, read the one page and go back.

Why this layer exists

Parsing has a notation wall and a handful of data-structure habits. Get those out of the way once, in plain language, and every algorithm afterwards is just an algorithm.

The pages

P1 · ready Sets & Languages A language is a set of strings. Membership, union, concatenation, Kleene star. P2 · ready Functions & the Notation Wall Total vs. partial functions, and every symbol you'll meet: Σ, ε, ⇒, ⊢, ⊆, →. P3 · ready The Cursor Pattern peek / advance / eof / mark / reset over an index. Every scanner and parser in the course is built on it. P4 · ready Java & JS Setup Exact toolchain, how to run and test one module, and the 40-line Assert helper that replaces JUnit. P5 · ready Trees Node, root, leaf, subtree; pre-order vs post-order; the shape of every tree-walk in the course. P6 · ready Automata Basics DFA / NFA, the transition function, pigeonhole, and the machine tower under the Chomsky hierarchy. P7 · ready Sets, Relations & Fixed Points Sets, closures, and the "start small, add what the rules force, stop when nothing changes" iteration. P8 · ready Big-O Quick Reference The four complexities the course uses, plus what "amortised O(1)" actually means. P9 · ready Induction & Recursion Structural recursion and structural induction are the same shape; base case + step. Worked example: the Thompson bound. P10 · added on demand Hash tables & scoping Written when Module 42 (symbol tables) needs it.

The course is built one module at a time; this layer grows the same way. Pages P1–P4 are enough for Module 1; P5 (Trees) arrives with Module 3.
