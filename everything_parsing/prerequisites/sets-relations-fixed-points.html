Sets, Relations &Fixed Points

FIRST sets, FOLLOW sets, nullable, ε-closure, the LR item sets — half the algorithms in this course have the same shape: start small, keep adding what the rules force, stop when nothing changes. That shape is a least fixed point.

01

Sets, quickly

  • Set — an unordered collection with no duplicates. {a, b} = {b, a, b}.
  • x ∈ S — membership. S ⊆ T — every element of S is in T.
  • ∅ — the empty set. |S| — its size.
  • Union S ∪ T, intersection S ∩ T, difference S \ T.
  • Power set 𝒫(S) — the set of all subsets of S. If |S| = n then |𝒫(S)| = 2ⁿ — the reason the subset construction (Module 13) can blow up.
02

Relations and closures

A relation R on a set is a set of pairs. "a can reach b in one step." The transitive closure R⁺ adds every pair reachable in one or more steps; the reflexive-transitive closure R* also adds (a, a) for every a (zero steps).

⇒ is a relation on sentential forms; ⇒* is its reflexive-transitive closure. ε-closure of an NFA state is the reflexive-transitive closure of "reachable by an ε-transition."

03

Least fixed points — the iteration pattern

Given a monotone function F on sets (adding to the input never removes from the output), the least fixed point is the smallest X with F(X) = X. You compute it by iterating:

X = ∅
repeat
    X' = F(X)
    if X' == X: return X      // nothing changed — fixed point reached
    X = X'

It terminates whenever the universe is finite (each pass adds at least one element, or stops). Every FIRST/FOLLOW/nullable computation in Part III is this loop with a specific F.

Why "least"

X = everything is often also a fixed point, but it's wrong — it claims more than the rules force. Starting from ∅ and only adding what a rule requires gives the least one, which is the answer you want: "exactly the tokens that really can appear here," not "all tokens, to be safe."

04

Pigeonhole

n + 1 items in n boxes ⇒ some box has ≥ 2. Used in Module 7: a run of p symbols through a p-state automaton revisits a state, creating a pumpable loop.
