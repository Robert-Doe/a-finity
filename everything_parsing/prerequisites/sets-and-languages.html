Sets & Languages

The entire field rests on one definition: a language is a set of strings. Nothing more. Parsing is the job of deciding, for one string, whether it is in the set — and if so, how it was built.

01

Alphabet, string, language

Alphabet  Σ  — a finite, non-empty set of symbols. Examples: {0,1}; the 128 ASCII characters; the set of token kinds {IDENT, NUMBER, PLUS, LPAREN, …}.

String  (over Σ) — a finite ordered sequence of symbols from Σ. The empty string is written ε (epsilon), length 0. |w| is the length of w.

Σ* — the set of all strings over Σ, including ε. Always infinite (once Σ is non-empty). Σ⁺ is Σ* without ε.

Language  L  — any subset of Σ*. Could be empty (∅), finite ({"cat","dog"}), or infinite (all valid Java programs).

Σ* is an infinite warehouse holding every string you could ever type. A language is a shelf in that warehouse — you drew a boundary and said "these ones belong together."

A grammar is a machine that prints the shelf's contents one by one. A parser is the clerk who takes a string you hand them and says "shelf 7, third from the left" — or "not stocked here."

02

Four operations you will see constantly

OperationDefinitionExample
Union L₁ ∪ L₂strings in either set{"a"} ∪ {"b"} = {"a","b"}
Concatenation L₁ · L₂every xy with x∈L₁, y∈L₂{"a","b"}·{"c"} = {"ac","bc"}
Power LⁿL concatenated with itself n times; L⁰ = {ε}{"ab"}² = {"abab"}
Kleene star L*L⁰ ∪ L¹ ∪ L² ∪ … — zero or more, always contains ε{"a"}* = {ε,"a","aa","aaa",…}

Regular expressions (P-page for Module 3) are exactly these operations written compactly: a|b is union, ab is concatenation, a* is Kleene star. That is the whole trick.

03

Why "set of strings" is the useful lens

It makes precise questions you can now actually answer with code:

  • Membership: is w ∈ L?  → a recogniser.
  • Structure: which rules produced w?  → a parser.
  • Comparison: is L₁ = L₂?  → decidable for regular languages, undecidable for context-free ones. (That single fact shapes half the course.)
Hold onto this

ε is a string. {ε} is a language containing one string. ∅ is a language containing no strings. {ε} ≠ ∅. Conflating these three is the single most common beginner slip, and Module 1's code has a check that fires exactly when a token pattern can match ε.
